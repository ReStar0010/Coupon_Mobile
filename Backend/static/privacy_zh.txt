• 下載並使用我們的行動應用程式（CouPro），或任何連結至本隱私權政策的其他應用程式
• 以其他相關方式與我們互動，包括任何銷售、行銷或活動

如有疑問或疑慮？閱讀本隱私權政策將有助於您了解您的隱私權與選擇。若您不同意我們的政策與做法，請勿使用我們的服務。若您仍有任何問題或疑慮，請透過 coupro707@gmail.com 與我們聯繫。

三、我們收集哪些資訊？

（一）您向我們提供的個人資訊
簡言之：我們收集您主動提供給我們的個人資訊。

當您於服務上註冊、表示有興趣取得我們或我們產品與服務的資訊、參與服務上的活動，或以其他方式與我們聯繫時，我們會收集您自願提供的個人資訊。

您提供的個人資訊。我們收集的個人資訊可能包括：
• 電子郵件地址
• 密碼
• 電話號碼
• 姓名（聯絡人姓名）
• 商家資訊（商店名稱、商店地址、商店類型、營業時間）
• 圖片與照片（您上傳的商店圖片、優惠券圖片）
• 交易與兌換資料（優惠券詳情、兌換記錄、用於驗證的客戶電話號碼）

敏感資訊。我們不處理敏感資訊。

（二）應用程式資料
若您使用我們的應用程式，若您選擇授權我們存取，我們亦可能收集以下資訊：
• 地理位置資訊。我們可能會請求存取或權限以從您的行動裝置追蹤基於位置的資訊，以提供特定基於位置的服務。您可於裝置設定中變更我們的存取或權限。
• 行動裝置存取。我們可能會請求存取您行動裝置的特定功能，包括相機及其他功能。您可於裝置設定中變更我們的存取或權限。

此資訊主要用於維護我們應用程式的安全與運作、疑難排解，以及我們的內部分析與報告目的。

（三）錯誤監控與效能資料
當您使用我們的行動應用程式時，我們會自動收集技術資料以改善穩定性與效能：
• 錯誤與當機報告 — 我們使用 Sentry 及類似服務，在應用程式遇到當機或錯誤時擷取錯誤報告、堆疊追蹤及裝置資訊，以協助我們修復錯誤並提升可靠性。
• 分析與效能指標 — 我們使用 Google Firebase（Firebase Analytics 與 Firebase Performance Monitoring）收集匿名化使用資料、應用程式效能指標（例如畫面載入時間、網路請求持續時間）及彙總分析，以了解應用程式使用方式並改善效能。

傳送至這些服務的資料已最小化，僅用於錯誤監控、分析及效能改善。您可透過 Sentry 與 Google Firebase 各自的隱私權政策進一步了解其做法。

（四）商家專屬資訊
若您以商家身分於我們的服務註冊，我們會收集提供商家服務所需的額外資訊，包括：
• 商店／商家名稱與地址
• 聯絡人資訊
• 營業時間與商店類型／類別
• 商店圖片與標誌
• 優惠券／促銷詳情（名稱、描述、數量、有效期間、圖片）
• 兌換記錄與交易資料
• 商家分析（優惠券瀏覽次數、兌換次數、使用統計）

（五）兌換用客戶資料
當商家處理優惠券兌換時，我們可能僅為驗證及完成兌換交易之目的而收集客戶電話號碼。此資料代表商家處理，並遵循資料最小化原則。

（六）Google API
我們對從 Google API 收到的資訊的使用，將遵守 Google API 服務使用者資料政策，包括有限使用要求。

您提供給我們的個人資訊必須真實、完整且準確，您必須將該個人資訊的任何變更通知我們。

簡言之：我們處理您的資訊以提供、改善及管理我們的服務、與您溝通、進行安全與詐騙防護，並遵守法律。我們亦可能在取得您同意後為其他目的處理您的資訊。

我們基於多種原因處理您的個人資訊，包括：
• 促進帳戶建立與驗證，並管理使用者帳戶
• 提供並促進向使用者交付服務
• 回覆使用者查詢／向使用者提供支援
• 履行及管理您透過服務進行的訂單、付款、退貨與換貨
• 若您選擇使用我們允許與其他使用者通訊的服務，則啟用使用者間通訊
• 徵求意見並就您對我們服務的使用與您聯繫
• 保護我們的服務，包括詐騙監控與防護
• 評估及改善我們的服務、產品、行銷與您的體驗
• 識別使用趨勢以改善我們的服務
• 提供商家服務，包括商店管理、優惠券建立與管理、兌換處理及商家分析服務
• 處理優惠券兌換，包括處理客戶電話號碼與兌換資料，以代表商家驗證及完成交易
• 向消費者顯示商家資訊，包括商店資訊、圖片與優惠券詳情，以促進優惠券發現與兌換流程
• 透過第三方錯誤監控（例如 Sentry）監控錯誤並改善穩定性，以修復當機與錯誤
• 透過分析與效能監控（例如 Firebase Analytics、Firebase Performance）衡量並改善效能，以優化應用程式速度與使用者體驗

五、我們何時以及與誰分享您的個人資訊？

簡言之：我們可能在本節所述特定情況下及／或與特定第三方分享資訊。

我們可能需要在以下情況分享您的個人資訊：
• 業務轉讓。我們可能於任何合併、公司資產出售、融資或我們業務全部或部分收購的談判中或與之相關時，分享或轉讓您的資訊。
• 當我們使用 Google Maps Platform API 時。我們可能與特定 Google Maps Platform API（例如 Google Maps API、Places API）分享您的資訊。Google Maps 使用 GPS、Wi-Fi 與基地台估算您的位置。我們會取得並在您裝置上快取您的位置。您可隨時透過與我們聯繫撤銷同意。
• 業務合作夥伴。我們可能與業務合作夥伴分享您的資訊，以向您提供特定產品、服務或促銷。
• 商家與消費者資料分享。當消費者兌換優惠券時，有限資訊（例如用於驗證的電話號碼）可能與相關商家分享以完成兌換交易。商家商店資訊與優惠券詳情會向消費者顯示以促進服務。
• 分析與報告。我們可能與商家分享彙總或匿名化資料以用於商家分析目的，包括優惠券效能指標、兌換統計與使用趨勢。
• 錯誤監控與效能服務。我們與 Sentry 分享有限技術資料（例如當機報告、錯誤日誌、效能指標）以進行錯誤監控，並與 Google Firebase（Firebase Analytics 與 Firebase Performance Monitoring）分享以進行分析與效能改善。這些供應商依其各自隱私權政策與我們的指示處理資料。

六、我們是否使用 Cookie 及其他追蹤技術？

簡言之：我們可能使用 Cookie 及其他追蹤技術以收集及儲存您的資訊。

我們可能使用 Cookie 及類似追蹤技術（如網路信標與像素）在您與我們服務互動時收集資訊。部分線上追蹤技術協助我們維護服務與您帳戶的安全、防止當機、修復錯誤、儲存您的偏好並協助基本網站功能。

我們亦允許第三方與服務供應商在我們服務上使用線上追蹤技術以進行分析與廣告，包括協助管理與顯示廣告、根據您的興趣客製廣告，或發送放棄購物車提醒（依您的通訊偏好而定）。

在我們的行動應用程式中，我們使用軟體開發套件（SDK）及類似技術進行錯誤監控（例如 Sentry）以及分析與效能監控（例如 Google Firebase Analytics 與 Firebase Performance）。這些協助我們偵測當機、衡量應用程式效能並以彙總方式了解使用模式。

七、我們保留您的資訊多久？

簡言之：除非法律另有規定，我們會在本隱私權政策所述目的所需期間內保留您的資訊。

我們僅會在本隱私權政策所述目的所需期間內保留您的個人資訊，除非法律要求或允許更長保留期（例如稅務、會計或其他法律要求）。本政策所述任何目的均不要求我們在使用者擁有我們帳戶的時間段之外保留您的個人資訊。

當我們不再有持續的合法業務需要處理您的個人資訊時，我們將刪除或匿名化該資訊，或若無法如此（例如因您的個人資訊已儲存於備份檔案中），則我們將安全儲存您的個人資訊並將其與任何進一步處理隔離，直至可刪除為止。

簡言之：我們旨在透過組織與技術安全措施系統保護您的個人資訊。

我們已實施適當且合理的技術與組織安全措施，旨在保護我們所處理任何個人資訊的安全。然而，儘管我們有保障措施並努力保護您的資訊，網路上任何電子傳輸或資訊儲存技術均無法保證 100% 安全，因此我們無法承諾或保證駭客、網路罪犯或其他未經授權的第三方無法突破我們的安全措施並不當收集、存取、竊取或修改您的資訊。

儘管我們將盡力保護您的個人資訊，往返我們服務的個人資訊傳輸風險由您自行承擔。您應僅在安全環境中存取服務。

簡言之：我們不會故意向 18 歲以下兒童收集資料或對其進行行銷。

我們不會故意向 18 歲以下兒童收集、徵求資料或對其進行行銷，亦不會故意出售該個人資訊。使用服務即表示您聲明您至少年滿 18 歲，或您為該未成年人的父母或監護人並同意該未成年受撫養人使用服務。

若我們得知已收集 18 歲以下使用者的個人資訊，我們將停用該帳戶並採取合理措施儘快從我們的記錄中刪除該資料。若您發現我們可能已從 18 歲以下兒童收集任何資料，請透過 coupro707@gmail.com 與我們聯繫。

十一、勿追蹤功能的控制

大多數網頁瀏覽器及部分行動作業系統與行動應用程式包含您可啟用的勿追蹤（「DNT」）功能或設定，以表示您不希望監控及收集您線上瀏覽活動資料的隱私偏好。

目前階段，尚無公認的統一技術標準用於識別與實施 DNT 信號。因此，我們目前不回應 DNT 瀏覽器信號或任何其他自動傳達您選擇不被線上追蹤的機制。若未來我們必須遵守的線上追蹤標準被採用，我們將於本隱私權政策的修訂版本中告知您該做法。
