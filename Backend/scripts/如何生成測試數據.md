# 如何生成自己的測試數據

本指南說明如何使用測試數據生成工具來創建自定義的測試數據。

## 快速開始

### 方法 1: 使用默認配置

最簡單的方式是直接指定階段，使用默認參數：

```bash
# 生成 Stage 1 的測試數據
python scripts/generate_merchant_test_data.py --stage 1

# 生成 Stage 5 的測試數據
python scripts/generate_merchant_test_data.py --stage 5
```

### 方法 2: 使用命令行參數自定義

你可以通過命令行參數覆蓋默認值：

```bash
# Stage 1: 基本計數指標
python scripts/generate_merchant_test_data.py --stage 1 \
  --num-active-templates 10 \
  --num-inactive-templates 5 \
  --num-store-templates 3 \
  --total-quantity-per-template 50 \
  --clicks-per-template 200

# Stage 2: EasyUse 模板分析
python scripts/generate_merchant_test_data.py --stage 2 \
  --num-store-templates 5 \
  --clicks-per-template 300 \
  --conversion-rate 0.25 \
  --time-range-days 30 \
  --nearby-click-ratio 0.7

# Stage 3: Exclusive 基礎指標
python scripts/generate_merchant_test_data.py --stage 3 \
  --num-exclusive-templates 5 \
  --coupons-per-template 200 \
  --clicks-per-template 500 \
  --redemption-rate 0.6 \
  --time-range-days 30 \
  --nearby-click-ratio 0.65

# Stage 4: Exclusive 進階指標
python scripts/generate_merchant_test_data.py --stage 4 \
  --num-exclusive-templates 3 \
  --coupons-per-template 150 \
  --redemption-rate 0.7 \
  --stranger-acquisition-ratio 0.8 \
  --sharing-rate 0.4 \
  --circulation-redemption-ratio 0.75 \
  --time-range-days 30

# Stage 5: 時間趨勢與邊界場景（使用默認配置即可）
python scripts/generate_merchant_test_data.py --stage 5
```

### 方法 3: 使用 JSON 配置文件（推薦）

創建一個 JSON 配置文件，可以更靈活地管理參數：

**創建 `my_custom_config.json`:**

```json
{
  "stage1": {
    "num_active_templates": 10,
    "num_inactive_templates": 5,
    "num_store_templates": 3,
    "total_quantity_per_template": 50,
    "clicks_per_template": 200
  },
  "stage2": {
    "num_store_templates": 5,
    "clicks_per_template": 300,
    "conversion_rate": 0.25,
    "time_range_days": 30,
    "nearby_click_ratio": 0.7
  },
  "stage3": {
    "num_exclusive_templates": 5,
    "coupons_per_template": 200,
    "clicks_per_template": 500,
    "redemption_rate": 0.6,
    "time_range_days": 30,
    "nearby_click_ratio": 0.65
  },
  "stage4": {
    "num_exclusive_templates": 3,
    "coupons_per_template": 150,
    "redemption_rate": 0.7,
    "stranger_acquisition_ratio": 0.8,
    "sharing_rate": 0.4,
    "circulation_redemption_ratio": 0.75,
    "time_range_days": 30
  }
}
```

然後使用配置文件：

```bash
python scripts/generate_merchant_test_data.py --stage 1 --config my_custom_config.json
python scripts/generate_merchant_test_data.py --stage 4 --config my_custom_config.json
```

## 各階段參數說明

### Stage 1: 基本計數指標

| 參數 | 說明 | 默認值 | 範例 |
|------|------|--------|------|
| `num_active_templates` | 活躍模板數量 | 3 | 10 |
| `num_inactive_templates` | 非活躍模板數量 | 2 | 5 |
| `num_store_templates` | Store 類型模板數量 | 2 | 3 |
| `total_quantity_per_template` | 每個模板的總數量 | 20 | 50 |
| `clicks_per_template` | 每個模板的點擊/曝光次數 | 50 | 200 |

### Stage 2: EasyUse 模板分析

| 參數 | 說明 | 默認值 | 範例 |
|------|------|--------|------|
| `num_store_templates` | Store 模板數量 | 2 | 5 |
| `clicks_per_template` | 每個模板的曝光次數 | 100 | 300 |
| `conversion_rate` | 轉換率（0-1） | 0.15 | 0.25 |
| `time_range_days` | 時間範圍（天） | 30 | 30 |
| `nearby_click_ratio` | 附近點擊比例（0-1） | 0.6 | 0.7 |

### Stage 3: Exclusive 基礎指標

| 參數 | 說明 | 默認值 | 範例 |
|------|------|--------|------|
| `num_exclusive_templates` | Exclusive 模板數量 | 3 | 5 |
| `coupons_per_template` | 每個模板生成的優惠券數 | 50 | 200 |
| `clicks_per_template` | 每個模板的曝光次數 | 150 | 500 |
| `redemption_rate` | 核銷率（0-1） | 0.4 | 0.6 |
| `time_range_days` | 時間範圍（天） | 30 | 30 |
| `nearby_click_ratio` | 附近點擊比例（0-1） | 0.6 | 0.65 |

### Stage 4: Exclusive 進階指標

| 參數 | 說明 | 默認值 | 範例 |
|------|------|--------|------|
| `num_exclusive_templates` | Exclusive 模板數量 | 2 | 3 |
| `coupons_per_template` | 每個模板生成的優惠券數 | 100 | 150 |
| `redemption_rate` | 總核銷率（0-1） | 0.5 | 0.7 |
| `stranger_acquisition_ratio` | 陌生獲客比例（0-1） | 0.6 | 0.8 |
| `sharing_rate` | 分享率（0-1） | 0.3 | 0.4 |
| `circulation_redemption_ratio` | 流動核銷比例（0-1） | 0.7 | 0.75 |
| `time_range_days` | 時間範圍（天） | 30 | 30 |

### Stage 5: 時間趨勢與邊界場景

Stage 5 主要測試時間範圍過濾和邊界場景，通常使用默認配置即可。它會自動生成：
- 不同時間範圍的數據（3/7/30/90 天）
- 空數據場景
- 高核銷率場景
- 低轉換率場景

## 測試生成的數據

生成數據後，你可以運行測試來驗證：

```bash
# 測試特定階段（會自動重新生成數據）
python scripts/test_merchant_statistics.py --stage 1

# 使用現有數據測試（不重新生成）
python scripts/test_merchant_statistics.py --stage 1 --no-generate

# 使用自定義配置生成並測試
python scripts/generate_merchant_test_data.py --stage 1 --config my_config.json
python scripts/test_merchant_statistics.py --stage 1 --config my_config.json --no-generate
```

## 注意事項

1. **數據庫**: 測試數據會寫入測試數據庫 (`db_test.sqlite3`)，不會影響生產數據
2. **覆蓋**: 每次生成會覆蓋現有的測試數據，如果需要保留，請先備份
3. **服務器**: 測試前確保測試服務器正在運行：
   ```bash
   ./run_test_server.sh
   ```
4. **參數範圍**: 
   - 比率參數（如 `conversion_rate`）應在 0-1 之間
   - 數量參數應為正整數
   - 時間範圍建議在 3-90 天之間

## 進階用法

### 組合使用配置文件與命令行參數

命令行參數會覆蓋配置文件中的值：

```bash
# 使用配置文件，但覆蓋特定參數
python scripts/generate_merchant_test_data.py --stage 3 \
  --config my_config.json \
  --redemption-rate 0.8
```

### 查看生成的數據統計

生成完成後，腳本會輸出統計信息：
- 創建的模板數量
- 生成的優惠券數量
- 創建的日誌條目數
- 創建的核銷記錄數

## 疑難排解

### 問題: 數據沒有生成

**解決方案**: 
1. 確保 Django 環境已正確設置
2. 檢查測試數據庫是否存在
3. 查看終端錯誤訊息

### 問題: 參數不生效

**解決方案**:
1. 檢查參數名稱是否正確（使用下劃線 `_` 而非連字符 `-`）
2. 確保參數類型正確（整數 vs 浮點數）
3. 查看腳本輸出的配置信息確認參數是否被讀取

### 問題: 數據不符合預期

**解決方案**:
1. 檢查參數的邏輯關係（例如：`redemption_rate` 不能大於 1）
2. 某些參數會互相影響（例如：`coupons_per_template` 和 `redemption_rate`）
3. 查看生成的數據統計，確認是否符合預期
